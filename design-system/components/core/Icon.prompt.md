Thin-line icon (Lucide subset, 1.5 stroke) for arrows, FAQ toggles, checklists, contact details and the six offering glyphs.

```jsx
<Icon name="arrow-right" size={18} />
<Icon name="flower" size={60} strokeWidth={1.25} />
```

UI: arrow-left, arrow-right, arrow-up-right, plus, minus, circle-plus, circle-minus, check, mail, map-pin, clock, menu.
Offerings: flower (Mindfulness), person-standing (Coaching), heart (Healing), sprout (Growth), hand-heart (Community), infinity (Balance).
