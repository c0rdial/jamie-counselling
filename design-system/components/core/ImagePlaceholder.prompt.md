Flat tinted stand-in for photography. Every image slot in Jamie Sulek uses this until real photos are supplied.

```jsx
<ImagePlaceholder label="Hero portrait" ratio="1710 / 2070" />
<ImagePlaceholder label="Retreat landscape" ratio="16 / 9" tone="ink" />
```

Tones: sand (default), cream, sage, ink (for image-backed CTAs with light text on top).
